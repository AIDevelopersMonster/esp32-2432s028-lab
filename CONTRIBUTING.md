# Участие в проекте

Приветствуются исправления распиновки, результаты проверки разных ревизий платы, новые небольшие примеры и фотографии собственного оборудования.

Перед pull request:

1. убедитесь, что код собирается для `ESP32 Dev Module`;
2. не добавляйте пароли Wi-Fi, токены и другие секреты;
3. укажите точную маркировку ревизии платы;
4. опишите использованные версии библиотек;
5. приложите вывод Serial Monitor или фотографию результата для аппаратных изменений;
6. не добавляйте изображения и схемы с неясной лицензией.

Новый пример должен решать одну понятную задачу и запускаться независимо от остальных примеров.
