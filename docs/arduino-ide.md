# Установка в Arduino IDE

## 1. Пакет ESP32

Откройте **File → Preferences** и добавьте URL менеджера плат Espressif, если он ещё не добавлен:

```text
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

Затем откройте **Tools → Board → Boards Manager**, найдите `esp32 by Espressif Systems` и установите пакет.

## 2. Библиотеки

Через **Library Manager** установите:

- `TFT_eSPI` by Bodmer;
- `XPT2046_Touchscreen` by Paul Stoffregen — для примера тачскрина.

Стандартные `WiFi`, `SD`, `SPI` и `time` входят в пакет ESP32.

## 3. Библиотека CYD_Board

Скопируйте каталог:

```text
libraries/CYD_Board
```

в каталог библиотек Arduino. Обычно это:

```text
Documents/Arduino/libraries/CYD_Board
```

После копирования перезапустите Arduino IDE.

## 4. Конфигурация TFT_eSPI

Найдите установленную библиотеку `TFT_eSPI` и сохраните резервную копию её файла `User_Setup.h`.

Затем замените его файлом:

```text
config/tft_espi/User_Setup.h
```

TFT_eSPI использует общую конфигурацию библиотеки, поэтому изменение может повлиять на другие ваши дисплейные проекты. Альтернативный вариант — подключить отдельный setup через `User_Setup_Select.h`.

## 5. Настройки платы

Рекомендуемый начальный набор:

| Параметр | Значение |
|---|---|
| Board | ESP32 Dev Module |
| Upload Speed | 921600, при ошибках 460800 или 115200 |
| CPU Frequency | 240 MHz |
| Flash Frequency | 40 MHz |
| Flash Mode | QIO; при проблемах DIO |
| Flash Size | 4 MB |
| Partition Scheme | Default 4MB with spiffs |
| Port | COM-порт CH340C платы |

## 6. Проверка

Начинайте с примеров в таком порядке:

1. `00_board_test`;
2. `01_display_test`;
3. `02_touch_test`;
4. `03_sd_test`;
5. `04_wifi_clock`.

Если прошивка не начинается автоматически, удерживайте BOOT, нажмите RESET, отпустите RESET и затем BOOT. Обычно CH340C и схема автозагрузки делают это без ручных действий.

## Типичные неисправности

### Белый или чёрный экран

- проверить, включена ли подсветка GPIO 21;
- проверить настройки TFT_eSPI;
- попробовать другую частоту SPI, например 27 МГц;
- проверить, что выбрана ILI9341, а не ST7789;
- проверить поворот экрана.

### Цвета перепутаны

В конфигурации TFT_eSPI может потребоваться `TFT_RGB_ORDER TFT_BGR` либо обратный вариант — это зависит от матрицы.

### Тачскрин реагирует зеркально

Настройте `touch.setRotation()` и примените собственное преобразование сырых координат после калибровки.

### Ошибка подключения к порту

- закрыть другие мониторы COM-порта;
- установить драйвер CH340;
- снизить Upload Speed;
- заменить USB-кабель на кабель с линиями данных.
