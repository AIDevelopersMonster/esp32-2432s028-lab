# Паспорта плат и исполнений

Этот раздел описывает конкретные исполнения дисплейных плат ESP32. Название на карточке товара недостаточно: под одним обозначением могут продаваться разные ревизии, типы тачскрина, USB-разъёмы, контроллеры дисплея и варианты разводки.

## Статусы достоверности

- `CONFIRMED_BY_MANUFACTURER` — подтверждено официальной спецификацией.
- `CONFIRMED_BY_INSPECTION` — подтверждено фотографиями, измерениями или тестом конкретной платы.
- `COMMUNITY_REPORTED` — подтверждено несколькими независимыми источниками.
- `SOURCE_REPORTED` — приведено одним техническим источником.
- `UNVERIFIED` — требует проверки.
