# Производители, продавцы и первичные источники

Этот раздел хранит ссылки на производителей, поставщиков, официальные страницы загрузок, китайские облачные каталоги и другие первичные источники по платам семейства **ESP32-2432S028 / ESP32-2432S028R / CYD**.

Цель раздела — не потерять важные URL, которые часто исчезают из карточек товара, меняются у продавцов или остаются только на китайском языке.

> Важно: наличие ссылки здесь не означает, что все файлы с неё проверены. Перед записью BIN всегда сверяйте модель платы, ревизию, размер flash, адрес записи и контрольную сумму.

## Что сохранять при обнаружении нового источника

Для каждого нового URL желательно фиксировать:

```text
Название организации
Страна / язык
Основной URL
Прямой URL загрузки
Какие модели поддерживаются
Какие типы файлов доступны
Дата проверки ссылки
Нужна ли регистрация
Есть ли пароль архива
Есть ли инструкция по адресам записи
Есть ли контрольные суммы
Примечания о лицензии
```

## Почему ссылки нужно дублировать в репозитории

Карточки товаров на AliExpress и аналогичных площадках часто меняются. Прямые ссылки на архивы могут быть удалены, заменены или спрятаны в изображениях описания. Поэтому в репозитории следует хранить как минимум:

- исходный URL;
- название файла или каталога;
- дату обнаружения;
- краткое описание содержимого;
- зеркальную ссылку только если её публикация разрешена;
- SHA-256 скачанных файлов после проверки.

Сами проприетарные архивы и заводские BIN не следует автоматически перезаливать в репозиторий без проверки лицензии и содержимого.
