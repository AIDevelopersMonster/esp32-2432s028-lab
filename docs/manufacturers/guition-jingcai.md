# Guition / Jingcai / JCZN1688

Статус источника: `PRIMARY_VENDOR_RESOURCE / PARTIALLY_VERIFIED`

Эта страница фиксирует основные URL и сведения о производителе/поставщике, связанном с дисплейными ESP32-модулями серий `ESP32-2432S028`, `JC2432W328`, `ESP32-3248S035` и родственными платами.

> Названия Guition, Jingcai и JCZN1688 встречаются в разных карточках товаров, документах и каталогах. Их точное корпоративное соотношение требует отдельной проверки, поэтому в репозитории они объединены как связанный кластер источников, а не как окончательно установленная юридическая структура.

## Основные URL

### Каталог загрузок Guition

- <https://www.guition.com/-download>

Полезно искать:

- PDF-спецификации;
- схемы;
- pinout;
- изображения плат;
- архивы примеров;
- заводские демо;
- инструкции по прошивке;
- документы по конкретным обозначениям моделей.

### Китайский файловый каталог JCZN1688

- <http://pan.jczn1688.com/1/ESP32%20module>

Это важный китайский источник с архивами по ESP32-модулям. Ссылка должна сохраняться даже при временной недоступности.

В каталоге могут встречаться:

- исходные проекты;
- BIN-файлы;
- factory demo;
- Arduino examples;
- ESP-IDF examples;
- PDF;
- схемы и распиновки;
- конфигурации LVGL;
- утилиты для записи.

## Связанные обозначения изделий

В материалах этого кластера источников встречаются или могут встречаться:

- ESP32-2432S028;
- ESP32-2432S028R;
- ESP32-2432S028C;
- JC2432W328;
- ESP32-3248S035R;
- ESP32-3248S035C;
- другие модели, где числа обычно кодируют разрешение или размер панели.

Нельзя считать два изделия совместимыми только из-за похожего имени.

## Заводские демонстрации

Для плат этого семейства обычно встречаются следующие классы демо:

- LVGL Widgets Demo;
- LVGL Benchmark;
- Factory Test;
- LCD Test;
- Touch Test;
- SD Test;
- RGB/LDR Test;
- multimedia/music demo;
- комплексное меню продавца.

Наличие одинакового визуального интерфейса не означает бинарную совместимость между R- и C-версиями или между 2,8- и 3,5-дюймовыми платами.

## Рекомендуемая процедура работы с материалами производителя

1. Сохранить исходный URL.
2. Скачать архив без распаковки.
3. Вычислить SHA-256 архива.
4. Сохранить список файлов.
5. Проверить наличие инструкции по адресам записи.
6. Отдельно определить тип каждого BIN.
7. Сравнить модель платы и аппаратную ревизию.
8. Не записывать файл до сохранения полного дампа своей платы.
9. После проверки добавить карточку в `docs/factory-firmware/FIRMWARE-CATALOG.md`.
