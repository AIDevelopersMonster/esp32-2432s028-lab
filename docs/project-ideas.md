# Идеи проектов

Плата особенно удобна там, где нужен небольшой автономный экран управления без отдельной разводки дисплея.

## Начальный уровень

- настольные часы и погодный экран;
- графический Wi-Fi-сканер;
- тестер датчиков I²C;
- счётчик импульсов;
- таймер, секундомер, Pomodoro;
- экран статуса домашней сети.

## Средний уровень

- MQTT-панель умного дома;
- пульт управления реле и освещением;
- регистратор данных на microSD;
- лабораторная панель источника питания;
- интерфейс генератора сигналов;
- компактный Modbus/RS-485 терминал через внешний трансивер.

## Продвинутый уровень

- интерфейс LVGL, разработанный в EEZ Studio или SquareLine Studio;
- Home Assistant дисплей через ESPHome;
- автономный конфигуратор устройств по Wi-Fi/BLE;
- сенсорная панель собственного прибора;
- универсальный стенд для демонстрации библиотек ESP32;
- веб-синхронизация настроек и журналов.

## Предлагаемая логика развития репозитория

Каждый законченный проект лучше размещать в отдельном каталоге `projects/NN_name`, сохраняя рядом:

- краткое техническое задание;
- схему подключения;
- список библиотек и их версии;
- фотографии результата;
- видео демонстрации;
- известные ограничения;
- лицензию на код и медиаматериалы.
