# 00 — Базовая проверка платы

Файл программы: [`00_board_test.ino`](00_board_test.ino)

Первый пример проверяет узлы, не требующие настройки TFT_eSPI или внешней сети:

- встроенный RGB-светодиод;
- аналоговый вход фоторезистора LDR;
- кнопку BOOT;
- библиотеку `CYD_Board`;
- вывод в Serial Monitor.

## Требования

- настроенная Arduino IDE;
- установлен пакет ESP32;
- библиотека `CYD_Board` скопирована в каталог библиотек Arduino;
- плата выбрана как **ESP32 Dev Module**;
- Serial Monitor настроен на **115200 бод**.

Общая инструкция: [docs/arduino-ide.md](../../docs/arduino-ide.md).

## Используемые выводы

| Узел | GPIO | Особенность |
|---|---:|---|
| RGB Red | 4 | активный LOW |
| RGB Green | 16 | активный LOW |
| RGB Blue | 17 | активный LOW |
| LDR | 34 | вход, ADC |
| BOOT | 0 | нажатие соответствует LOW |

GPIO 34 работает только как вход. GPIO 0 является загрузочным выводом, поэтому не удерживайте BOOT во время reset без необходимости.

## Запуск

1. Откройте `00_board_test.ino`.
2. Подключите плату по USB.
3. Выберите плату и COM-порт.
4. Загрузите скетч.
5. Откройте Serial Monitor на 115200 бод.

## Ожидаемый результат

RGB-светодиод циклически показывает:

```text
красный → зелёный → синий → выключен
```

В Serial Monitor примерно каждые 700 мс выводится строка:

```text
LDR=1234, BOOT=released
```

При нажатии BOOT:

```text
LDR=1234, BOOT=pressed
```

Значение LDR должно изменяться при освещении или закрытии фоторезистора рукой. Абсолютные значения не нормированы и зависят от освещения и конкретного экземпляра платы.

## Критерий успеха

Пример считается работающим, если:

- прошивка запускается без непрерывного reset;
- три цвета RGB визуально различимы;
- состояние BOOT меняется при нажатии;
- значение LDR изменяется при заметном изменении освещения.

## Типичные проблемы

### Светодиод работает наоборот

Для встроенного RGB используется активный уровень LOW. Не заменяйте вызовы `cyd::setRgb()` прямой логикой HIGH/LOW без учёта инверсии.

### BOOT всегда pressed

Проверьте, не удерживается ли кнопка, нет ли замыкания GPIO 0 на GND и подходит ли профиль платы.

### LDR не меняется

Проверьте GPIO 34, попробуйте яркий источник света и полное закрытие датчика. Небольшое колебание ADC при постоянном освещении нормально.
