# 01 — Проверка дисплея ILI9341

## Статус

**ПРОВЕРЕНО: РАБОТАЕТ**

Дата проверки: **07.08.2026**

Фактически подтверждено на плате ESP32-2432S028R:

- подсветка TFT включается;
- контроллер дисплея инициализируется;
- изображение выводится стабильно;
- landscape-ориентация 320×240 работает;
- заголовок `ESP32-2432S028R` отображается;
- строка `ILI9341 display test` отображается;
- пять тестовых цветовых полей выводятся;
- рамка отображается;
- на экране появляется сообщение `Display initialized successfully`.

По представленному фото тест **01_display_test пройден**. Фотография подтверждает работоспособность вывода изображения и базовых цветов; точную колориметрическую оценку оттенков по фотографии не выполняем.

```text
TEST_01_DISPLAY_PASS
ILI9341_INITIALIZATION_CONFIRMED
TFT_BACKLIGHT_CONFIRMED
LANDSCAPE_320X240_CONFIRMED
TEXT_OUTPUT_CONFIRMED
COLOR_FIELDS_OUTPUT_CONFIRMED
```

Это **второй тест** последовательности примеров. Первый тест — [`00_board_test`](../00_board_test/README.md), где проверяется установка нашей библиотеки `CYD_Board` и базовое оборудование платы.

Файл программы: [`01_display_test.ino`](01_display_test.ino)

Пример проверяет:

- инициализацию TFT-контроллера;
- корректность конфигурации `TFT_eSPI`;
- ориентацию экрана;
- вывод текста, рамки и базовых цветов;
- управление подсветкой через профиль `CYD_Board`.

Для дисплея нужна отдельная библиотека `TFT_eSPI` и наша конфигурация `User_Setup.h`.

Пошаговая инструкция:

В ней показано:

## Требования

- успешно выполнен `00_board_test`;
- установлена и проверена библиотека `CYD_Board`;
- выполнена настройка Arduino IDE;
- установлена библиотека `TFT_eSPI`;
- применён файл `config/tft_espi/User_Setup.h`;
- выбрана плата **ESP32 Dev Module**.

Общая инструкция Arduino IDE: [docs/arduino-ide.md](../../docs/arduino-ide.md).

## Используемые выводы TFT

| Сигнал | GPIO |
|---|---:|
| MISO | 12 |
| MOSI | 13 |
| SCLK | 14 |
| CS | 15 |
| DC | 2 |
| RST | не подключён, `-1` |
| Backlight | 21 |

## Запуск

1. Убедитесь, что `00_board_test` уже работает.
2. Установите и настройте `TFT_eSPI` по инструкции выше.
3. Откройте `01_display_test.ino`.
4. Нажмите **Verify**.
5. Загрузите скетч на плату.
6. После reset наблюдайте экран.

Serial Monitor для этого примера не обязателен.

## Ожидаемый результат

Экран работает в landscape-ориентации 320×240 и показывает:

- заголовок `ESP32-2432S028R`;
- строку `ILI9341 display test`;
- пять цветных квадратов: красный, зелёный, синий, голубой и пурпурный;
- серую рамку;
- зелёную строку об успешной инициализации.

## Критерий успеха

Пример считается работающим, если:

- подсветка включена;
- изображение стабильно и не мерцает;
- текст читается;
- ориентация landscape соответствует 320×240;
- цветные поля различимы;
- отсутствуют заметные полосы, сдвиги или случайные пиксели.

## Типичные проблемы

### Ошибка `CYD_Board.h: No such file or directory`

Библиотека `CYD_Board` не установлена или установлена не в тот каталог. Вернитесь к инструкции:

- [CYD_Board — установка и первая проверка](../../libraries/CYD_Board/README.md)

### Ошибка `TFT_eSPI.h: No such file or directory`

Установите `TFT_eSPI by Bodmer` через Arduino Library Manager и выполните:

- [Установка и настройка TFT_eSPI](../../docs/tft-espi-installation.md)

### Белый экран

Проверьте:

- включение подсветки GPIO 21;
- выбор `ILI9341_DRIVER`;
- значения TFT CS, DC, MOSI и SCLK;
- что файл `User_Setup.h` действительно заменён или выбран через `User_Setup_Select.h`.

### Чёрный экран

Проверьте питание, подсветку и загрузку скетча. Чёрный фон является нормальным только при наличии текста и цветных полей.

### Неверные цвета

Для конкретной матрицы может потребоваться настройка RGB/BGR в TFT_eSPI. Не меняйте её только по одному спорному оттенку: сначала сравните все пять цветовых полей.

### Изображение повёрнуто

В примере используется:

```cpp
tft.setRotation(1);
```

Близкая ревизия платы может требовать другой rotation, но это уже отдельная адаптация профиля.
