# 02 — Проверка тачскрина XPT2046

## Статус

**ПРОВЕРЕНО: БАЗОВЫЙ RAW TOUCH РАБОТАЕТ**

Дата проверки: **07.08.2026**

По фактическому запуску скетча на ESP32-2432S028R подтверждено:

- TFT продолжает работать во время опроса тачскрина;
- XPT2046 обнаруживает касание;
- на дисплей выводятся сырые значения `X`, `Y` и `Z`;
- значения давления/контакта `Z` получаются ненулевыми;
- интерфейс теста отображается стабильно.

На представленном фото зафиксировано одно из реальных измерений:

```text
X:3222 Y:3167 Z:1216
```

Это подтверждает прохождение основного функционального этапа — связь ESP32 с XPT2046 и получение raw-данных работает.

```text
TEST_02_RAW_TOUCH_BASIC_PASS
XPT2046_COMMUNICATION_CONFIRMED
RAW_X_OUTPUT_CONFIRMED
RAW_Y_OUTPUT_CONFIRMED
RAW_Z_OUTPUT_CONFIRMED
TFT_AND_TOUCH_SIMULTANEOUS_OPERATION_CONFIRMED
```

Пример выводит **сырые**, ещё не откалиброванные координаты резистивного тачскрина:

- `X` — сырая координата по одной оси;
- `Y` — сырая координата по другой оси;
- `Z` — условная величина давления/контакта.

Значения отображаются одновременно на TFT и в Serial Monitor.

## Требования

Перед запуском этого теста должны быть выполнены предыдущие шаги:

- успешно работает пример [01_display_test](../01_display_test/README.md);
- установлены [`TFT_eSPI`](../../docs/tft-espi-installation.md) и [`XPT2046_Touchscreen`](../../docs/xpt2046-touchscreen-installation.md);
- установлена наша библиотека [`CYD_Board`](../../libraries/CYD_Board/README.md);
- применена конфигурация [`config/tft_espi/User_Setup.h`](../../config/tft_espi/User_Setup.h) по [инструкции TFT_eSPI](../../docs/tft-espi-installation.md);
- Serial Monitor настроен на **115200 бод**.

Для `XPT2046_Touchscreen` в проекте есть отдельная пошаговая инструкция:

**[Установка XPT2046_Touchscreen для ESP32-2432S028](../../docs/xpt2046-touchscreen-installation.md)**

В ней показано, как установить оригинальную библиотеку **XPT2046_Touchscreen by Paul Stoffregen** через Arduino Library Manager, проверить файл `XPT2046_Touchscreen.h`, понять используемый отдельный SPI и проверить компиляцию `02_touch_test.ino`.

## Используемые выводы тачскрина

| Сигнал | GPIO |
|---|---:|
| IRQ | 36 |
| MOSI | 32 |
| MISO | 39 |
| CLK | 25 |
| CS | 33 |

Это отдельная SPI-группа выводов. Не следует автоматически считать её тем же SPI-интерфейсом, что TFT или microSD.

## Запуск

1. Убедитесь, что `01_display_test` уже работает.
2. Установите `XPT2046_Touchscreen` по [инструкции](../../docs/xpt2046-touchscreen-installation.md).
3. Откройте `02_touch_test.ino`.
4. Нажмите **Verify**.
5. Загрузите скетч.
6. Откройте Serial Monitor на 115200 бод.
7. Нажимайте стилусом или пальцем в разных местах экрана.

Для резистивного тачскрина стилус обычно даёт более устойчивый контакт, чем лёгкое касание пальцем.

## Ожидаемый результат

На экране появляется заголовок:

```text
XPT2046 raw touch test
```

При касании обновляется строка вида:

```text
X:1234 Y:2870 Z:560
```

В Serial Monitor выводятся строки:

```text
x=1234 y=2870 z=560
```

При перемещении точки касания значения X и Y должны систематически изменяться. Одна или обе оси могут быть инвертированы относительно экранных координат — для сырых данных это нормально.

## Критерий успеха

Пример считается полностью проверенным по всей поверхности, если:

- касание обнаруживается в большинстве областей экрана;
- X и Y заметно меняются при перемещении точки;
- Z при реальном нажатии больше фонового значения;
- после отпускания экран не продолжает бесконечно регистрировать касание;
- TFT остаётся стабильным во время чтения touch.

Текущий подтверждённый статус относится к базовой работоспособности raw touch. Полный диапазон поверхности и калибровка ещё не зафиксированы этим одним фотоснимком.

## Что этот пример не делает

Он не выполняет:

- четырёхточечную калибровку;
- преобразование raw X/Y в пиксели 0…319 и 0…239;
- коррекцию инверсии или перестановки осей;
- фильтрацию дрожания;
- долговременное хранение коэффициентов.

Поэтому эти числа нельзя прямо использовать как экранные координаты интерфейса.

## Типичные проблемы

### `XPT2046_Touchscreen.h: No such file or directory`

Библиотека не установлена или Arduino IDE её не видит. Выполните:

- [Установка XPT2046_Touchscreen](../../docs/xpt2046-touchscreen-installation.md)

### Всегда одни и те же X/Y

Проверьте CS 33, CLK 25, MOSI 32 и MISO 39, а также установленную библиотеку XPT2046.

### Касание не обнаруживается

Проверьте IRQ 36 и попробуйте более уверенное нажатие стилусом. GPIO 36 является входом и не поддерживает обычный внутренний pull-up как стандартный выходной GPIO.

### Координаты зеркальные или оси перепутаны

Для raw-теста это ожидаемо. Исправление выполняется на этапе калибровки, а не изменением документации к этому примеру.

### TFT портится при касании

Это указывает на проблему конфигурации SPI, выбора контроллеров или линий CS. Данный пример использует отдельный `SPIClass` для touch.
