# 03 — Проверка microSD

## Текущий статус проверки

**ЧАСТИЧНО ПОДТВЕРЖДЕНО НА РЕАЛЬНОЙ ПЛАТЕ — 07.08.2026**

Получен фактический вывод:

```
ets Jul 29 2019 12:21:46

rst:0x1 (POWERON_RESET),boot:0x13 (SPI_FAST_FLASH_BOOT)
configsip: 0, SPIWP:0xee
clk_drv:0x00,q_drv:0x00,d_drv:0x00,cs0_drv:0x00,hd_drv:0x00,wp_drv:0x00
mode:DIO, clock div:2
load:0x3fff0030,len:4640
load:0x40078000,len:15632
load:0x40080400,len:3164
entry 0x4008059c
Card size: 30250 MB
```

Это уже подтверждает:

- ESP32 загрузился;
- microSD успешно смонтирована;
- карта определяется библиотекой `SD`;
- размер карты читается;
- фактически получено `Card size: 30250 MB`.

Поскольку в приведённом выводе пока нет строк `FILE:` или `DIR :`, проверка чтения заранее подготовленных файлов ещё не зафиксирована. Для полного прохождения теста создайте на карте контрольные файлы одним из способов ниже и повторите reset.

```
SD_MOUNT_CONFIRMED
SD_CARD_DETECTED
SD_CARD_SIZE_CONFIRMED
CARD_SIZE_REPORTED_30250_MB
DIRECTORY_CONTENT_CHECK_PENDING
```

Файл программы: [`03_sd_test.ino`](03_sd_test.ino)

Пример проверяет:

- инициализацию microSD;
- отдельную SPI-группу карты;
- определение типа и размера карты;
- чтение корневого каталога;
- рекурсивный вывод папок и файлов до двух уровней.

## Требования

- установлена наша библиотека [`CYD_Board`](../../libraries/CYD_Board/README.md);
- установлен пакет ESP32 для Arduino IDE, содержащий стандартные библиотеки `SPI` и `SD`;
- microSD вставлена в плату;
- Serial Monitor настроен на **115200 бод**.

`TFT_eSPI` и `XPT2046_Touchscreen` для этого примера не требуются.

## Используемые выводы microSD

| Сигнал | GPIO |
|---|---:|
| MISO | 19 |
| MOSI | 23 |
| SCLK | 18 |
| CS | 5 |

Эта SPI-группа отличается от выводов TFT и тачскрина.

# Подготовка карты — что именно нужно сделать

Текущий `03_sd_test.ino` **не создаёт и не изменяет файлы на карте**. Он намеренно работает как read-only тест: монтирует карту и выводит существующие каталоги и файлы.

Поэтому перед полной проверкой нужно создать на microSD два контрольных файла:

```
/hello.txt
/data/test.txt
```

Содержимое файлов может быть любым. Ниже приведены два полностью воспроизводимых способа для Windows.

## Вариант A — через Проводник Windows

1. Выключите питание ESP32 и извлеките microSD.
2. Вставьте карту в картридер компьютера.
3. Откройте **Этот компьютер / This PC**.
4. Найдите microSD и запомните букву диска, например `E:`.
5. Откройте корень карты.
6. Создайте файл:

```
hello.txt
```

7. В `hello.txt` запишите, например:

```
ESP32-2432S028 microSD test
```

8. В корне карты создайте папку:

```
data
```

9. В папке `data` создайте файл:

```
test.txt
```

10. В `test.txt` запишите, например:

```
nested file test
```

11. В итоге на карте должна получиться структура:

```
E:\
├── hello.txt
└── data\
    └── test.txt
```

12. Выполните штатное безопасное извлечение карты в Windows.
13. При отключённом питании вставьте microSD обратно в ESP32-2432S028R.
14. Включите плату или нажмите RESET.

## Вариант B — через PowerShell CLI

Сначала вставьте microSD в картридер и определите её букву в Проводнике Windows. В примере ниже используется `E:`.

**Обязательно замените `E:` на фактическую букву своей microSD.**

В PowerShell выполните:

```
$sd = "E:"

Set-Content -Path "$sd\hello.txt" `
  -Value "ESP32-2432S028 microSD test" `
  -Encoding ascii

New-Item -Path "$sd\data" `
  -ItemType Directory `
  -Force | Out-Null

Set-Content -Path "$sd\data\test.txt" `
  -Value "nested file test" `
  -Encoding ascii
```

Проверить, что файлы действительно появились:

```
Get-ChildItem "E:\" -Recurse |
  Select-Object FullName, Length
```

Для карты с буквой `E:` ожидается примерно:

```
FullName          Length
--------          ------
E:\data
E:\hello.txt         ...
E:\data\test.txt     ...
```

После проверки выполните безопасное извлечение карты средствами Windows, вставьте её в ESP32 при отключённом питании и запустите тест.

## Почему Serial Monitor не создаёт эти файлы

В текущей версии `03_sd_test.ino` Serial Monitor используется **только для вывода результатов**. Скетч не разбирает команды из Serial и не содержит функций создания тестовых файлов.

То есть вводить в Serial Monitor команды вроде `mkdir`, `echo` или `touch` бессмысленно — это не командная строка файловой системы microSD.

Автоматическую запись и последующее чтение лучше проверять отдельным тестом записи, чтобы этот пример оставался безопасным read-only тестом карты.

## Форматирование карты

Если карта уже даёт строку:

```
Card size: 30250 MB
```

то для этого экземпляра монтирование уже работает и **переформатировать карту только ради текущего теста не нужно**.

Если `SD.begin()` не работает, используйте карту с совместимой файловой системой. Для типичных карт этого проекта предпочтителен FAT32. Перед форматированием сохраните нужные данные: форматирование удаляет содержимое карты.

## Запуск теста

1. Подготовьте `hello.txt` и `data/test.txt` одним из способов выше.
2. Выключите питание платы.
3. Вставьте microSD в разъём платы.
4. Подключите ESP32 по USB.
5. Откройте `03_sd_test.ino`.
6. Нажмите **Verify**.
7. Нажмите **Upload**.
8. Откройте Serial Monitor.
9. Установите скорость:

```
115200 baud
```

10. Если начало вывода было пропущено, нажмите кнопку RESET/EN один раз.

Не извлекайте карту во время активного обращения к файловой системе.

## Ожидаемый результат для текущей карты

С учётом уже полученного результата начало должно содержать:

```
Card size: 30250 MB
```

После подготовки контрольных файлов должны также появиться строки примерно такого вида:

```
Card size: 30250 MB
FILE: hello.txt                SIZE: 29
DIR : data
FILE: test.txt                 SIZE: 16
```

Точные размеры файлов могут немного отличаться в зависимости от их содержимого и перевода строки. Для прохождения теста важны сами имена файлов и каталогов, а не конкретные числа `SIZE`.

## Критерий успеха

Пример считается полностью работающим, если:

- отсутствует сообщение `microSD mount failed`;
- карта определяется не как `CARD_NONE`;
- выводится ненулевой размер карты;
- виден `hello.txt`;
- виден каталог `data`;
- внутри `data` виден `test.txt`;
- повторный reset даёт согласованный результат.

## Типичные проблемы

### Выводится только `Card size`, но нет `FILE:` и `DIR :`

Это не обязательно ошибка SD-интерфейса. Если корень карты пуст, скетчу просто нечего перечислять.

Создайте контрольные файлы точно по инструкции выше и повторите reset.

### `microSD mount failed`

Проверьте:

- карту и её файловую систему;
- полную установку карты в разъём;
- GPIO 18, 19, 23 и CS 5;
- питание платы и качество USB-кабеля;
- другую карту меньшей ёмкости, отформатированную FAT32.

### `No microSD card detected`

SPI-обмен мог начаться, но библиотека не распознала носитель. Извлеките и вставьте карту при отключённом питании, затем повторите тест.

### Каталог пуст

Проверьте карту на компьютере и убедитесь, что `hello.txt` находится именно в корне карты, а `test.txt` — именно в папке `data`.

### Имена или размеры выглядят странно

Этот минимальный пример не предназначен для проверки всех вариантов длинных имён, Unicode, повреждённых файловых систем или exFAT.

## Ограничения

Пример только читает каталог. Он не проверяет:

- запись и последующее чтение данных;
- устойчивость при отключении питания;
- безопасное извлечение карты;
- одновременную работу SD с TFT и touch;
- bounded archive или ротацию логов.
