# 04 — Wi-Fi часы с NTP

Файл программы: [`04_wifi_clock.ino`](04_wifi_clock.ino)

Пример объединяет:

- подключение ESP32 к Wi-Fi;
- синхронизацию времени через NTP;
- вывод даты и времени на TFT;
- периодическое обновление экрана.

## Требования

- успешно работает пример [01_display_test](../01_display_test/README.md);
- установлены `TFT_eSPI` и `CYD_Board`;
- применена конфигурация TFT_eSPI;
- доступна сеть Wi-Fi 2,4 ГГц с выходом в интернет;
- создан локальный файл `secrets.h`.

ESP32 этой платы не подключается к сети 5 ГГц без отдельной точки доступа 2,4 ГГц.

## Подготовка `secrets.h`

В папке примера уже есть:

```text
secrets.example.h
```

Скопируйте его как:

```text
secrets.h
```

и заполните:

```cpp
#pragma once

#define WIFI_SSID "имя_вашей_сети"
#define WIFI_PASSWORD "пароль_вашей_сети"
```

Не публикуйте настоящий `secrets.h` в Git. Шаблон предназначен только для локального копирования.

## Часовой пояс

В исходном примере установлено время UTC:

```cpp
constexpr long GMT_OFFSET_SECONDS = 0;
constexpr int DAYLIGHT_OFFSET_SECONDS = 0;
```

Для постоянного смещения измените `GMT_OFFSET_SECONDS`. Например, UTC+3:

```cpp
constexpr long GMT_OFFSET_SECONDS = 3 * 3600;
```

Автоматические сезонные переходы этот минимальный пример не реализует. Для точной локальной зоны лучше использовать TZ-строку и отдельный расширенный пример.

## Запуск

1. Создайте и заполните `secrets.h`.
2. Откройте `04_wifi_clock.ino`.
3. Выберите **ESP32 Dev Module** и COM-порт.
4. Загрузите скетч.
5. Наблюдайте сообщения на TFT.

## Ожидаемый результат

Сначала экран показывает:

```text
Connecting to Wi-Fi...
```

После подключения и запуска синхронизации:

```text
Time synchronized
```

Затем крупно отображается время:

```text
12:34:56
```

и ниже дата:

```text
2026-08-06
```

Обновление выполняется примерно четыре раза в секунду.

## Критерий успеха

Пример считается работающим, если:

- плата подключается к указанной сети;
- не появляется окончательное сообщение `Wi-Fi connection failed`;
- после синхронизации отображаются правдоподобные дата и время;
- секунды увеличиваются без постоянных зависаний и reset;
- TFT остаётся стабильным во время работы Wi-Fi.

## Типичные проблемы

### `Wi-Fi connection failed`

Проверьте:

- SSID и пароль;
- наличие сети 2,4 ГГц;
- уровень сигнала;
- отсутствие captive portal;
- что `secrets.h` находится в той же папке, что `.ino`.

Тайм-аут подключения в примере составляет около 20 секунд.

### Время не появляется после подключения

Проверьте доступ в интернет, DNS и доступность NTP. Используются серверы:

```text
pool.ntp.org
time.nist.gov
```

### Время сдвинуто на несколько часов

Настройте `GMT_OFFSET_SECONDS`. Текущий исходник использует UTC.

### После открытия примера ошибка `secrets.h: No such file or directory`

Создайте `secrets.h` копированием `secrets.example.h`. Не переименовывайте только шаблон в репозитории, если хотите сохранить безопасный пример для других пользователей.

## Ограничения

Пример не реализует:

- автоматический выбор часового пояса;
- DST по календарным правилам;
- повторное подключение после длительной потери Wi-Fi;
- автономные часы RTC;
- сохранение последнего времени;
- защищённое пользовательское меню для ввода Wi-Fi.
