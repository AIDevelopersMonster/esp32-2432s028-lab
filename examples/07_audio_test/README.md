# 07 — Audio / GPIO26 DAC test

## Статус

**АППАРАТНЫЙ АУДИОТРАКТ ПОДТВЕРЖДЁН, СТАБИЛЬНОСТЬ НЕ ПОДТВЕРЖДЕНА**

На реальной ESP32-2432S028R подтверждено прохождение тестового сигнала по цепи:

```text
GPIO26 / DAC2 -> onboard audio amplifier -> P4 -> 8-ohm speaker
```

Тестовые сигналы 440, 880 и 1760 Hz были слышны через динамик, подключённый к штатному разъёму P4.

Файл программы: [`07_audio_test.ino`](07_audio_test.ino)

## Важное замечание по аппаратному тестированию

При тестировании с 8-омным динамиком возникла проблема: при увеличенной амплитуде сигнала DAC наблюдались сбои USB/UART, включая повреждение данных Serial и периодическую потерю COM-порта.

Для продолжения тестирования эту проблему обошли уменьшением амплитуды сигнала GPIO26/DAC2 до очень низкого уровня — примерно `128 +/- 2` кода DAC.

В таком режиме удалось устойчиво воспроизвести тестовые сигналы:

```text
440 Hz
880 Hz
1760 Hz
```

После завершения воспроизведения ESP32 продолжал выполнять программу и выдавать контрольные сообщения `ESP32 ALIVE`.

**Это не является решением обнаруженной проблемы и не является рекомендуемым режимом эксплуатации аудиовыхода.** Найденный низкоуровневый режим использовался только как диагностический способ подтвердить работоспособность аудиотракта.

**Анализ причин возникшей нестабильности на данном этапе не производился.**

Для использования аудиотракта в реальном устройстве требуется отдельное исследование его схемотехники, питания и допустимых режимов работы.

## Что проверяет пример

В проектной распиновке аудиотракт платы связан с `GPIO26`. На оригинальном ESP32 этот вывод является вторым 8-битным DAC-каналом, поэтому тест формирует аналогоподобную периодическую последовательность через `dacWrite()`.

Цель теста — только функционально проверить наличие звука и прохождение сигнала через штатный аудиотракт платы.

## Что требуется

- ESP32-2432S028R / CYD;
- проверенные настройки Arduino IDE из [`docs/arduino-ide.md`](../../docs/arduino-ide.md);
- динамик 8 ohm, подключённый к штатному разъёму P4;
- Serial Monitor на `115200` baud.

## Проверенные настройки Arduino IDE для лаборатории

```text
Board: ESP32 Dev Module
CPU Frequency: 240 MHz
Flash Frequency: 40 MHz
Flash Mode: DIO
Flash Size: 4 MB
PSRAM: Disabled
Upload Speed: 115200
Serial Monitor: 115200 baud
```

При этих настройках загрузка платы подтверждена строкой ROM boot log:

```text
mode:DIO, clock div:2
```

## Результат теста

Получены три различимых по высоте тона:

```text
низкий -> средний -> высокий
440 Hz -> 880 Hz -> 1760 Hz
```

В диагностическом низкоуровневом режиме последовательность завершалась штатно, после чего ESP32 продолжал работать:

```text
AUDIO TEST FINISHED
ESP32 should now remain running.
ESP32 ALIVE: ...
ESP32 ALIVE: ...
ESP32 ALIVE: ...
```

Этот результат подтверждает наличие рабочего пути от GPIO26/DAC2 до динамика, но **не подтверждает пригодность штатного аудиотракта для реального применения на произвольной громкости или мощности**.

## Что НЕ подтверждено

Тест не подтверждает:

- допустимую рабочую амплитуду;
- максимальную громкость;
- выходную мощность;
- стабильность аудиотракта при длительной работе;
- качество звука;
- коэффициент гармоник;
- частотную характеристику;
- причины наблюдавшихся сбоев USB/UART;
- пригодность найденного режима `128 +/- 2` для конечного устройства.

## Ограничения и безопасность

Не подключайте низкоомный динамик непосредственно к GPIO26 ESP32. Динамик должен подключаться только через предназначенный для него аудиотракт/усилитель.

На исследованной плате динамик подключался к штатному двухконтактному разъёму P4.

Найденное уменьшение амплитуды следует рассматривать только как лабораторный обход проблемы для подтверждения прохождения сигнала, а не как исправление схемы или рекомендацию по эксплуатации.

## Техническая основа

Для оригинального ESP32 Arduino API предоставляет `dacWrite(pin, value)`, а GPIO26 соответствует DAC2.

Официальная документация Espressif:

- <https://docs.espressif.com/projects/arduino-esp32/en/latest/api/dac.html>
