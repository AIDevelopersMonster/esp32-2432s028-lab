# 07 — Audio / GPIO26 DAC test

## Статус

**ГОТОВО К ПРОВЕРКЕ НА РЕАЛЬНОЙ ПЛАТЕ**

Пример пока не помечен как `VERIFIED`: требуется фактическая проверка звука или измерение сигнала на конкретной ESP32-2432S028R.

Файл программы: [`07_audio_test.ino`](07_audio_test.ino)

## Что проверяет пример

В проектной распиновке аудиотракт платы связан с `GPIO26`. На оригинальном ESP32 этот вывод является вторым 8-битным DAC-каналом, поэтому тест формирует аналогоподобную периодическую последовательность непосредственно через `dacWrite()`.

Скетч последовательно воспроизводит три различимых частоты:

```
440 Hz
880 Hz
1760 Hz
```

Каждый тон длится примерно 1,5 секунды, между тонами есть короткие паузы, затем последовательность повторяется.

## Что требуется

- ESP32-2432S028R / CYD;
- проверенные настройки Arduino IDE из [`docs/arduino-ide.md`](../../docs/arduino-ide.md);
- библиотека [`CYD_Board`](../../libraries/CYD_Board/README.md);
- подходящий динамик/нагрузка, подключённые через штатный аудиотракт конкретной ревизии платы.

Дополнительные Arduino-библиотеки не требуются.

## Проверенные настройки Arduino IDE для лаборатории

```
Board: ESP32 Dev Module
CPU Frequency: 240 MHz
Flash Frequency: 40 MHz
Flash Mode: DIO
Flash Size: 4 MB
PSRAM: Disabled
Upload Speed: 115200
Serial Monitor: 115200 baud
```

## Запуск

1. Убедитесь, что динамик или другая нагрузка подключены к предназначенному для аудио выходу вашей ревизии CYD.
2. Откройте `07_audio_test.ino`.
3. Выполните **Verify**.
4. Выполните **Upload**.
5. Откройте Serial Monitor на `115200` бод.

После старта ожидается:

```
ESP32-2432S028R GPIO26 DAC audio test
Audio/DAC pin: GPIO 26
AUDIO_TEST_READY
Expected sequence: 440 Hz -> 880 Hz -> 1760 Hz -> repeat
```

Далее для каждого тона выводятся строки вида:

```
AUDIO_TONE_START frequency=440Hz duration=1500ms
AUDIO_TONE_END frequency=440Hz
```

## Ожидаемый физический результат

Должны быть слышны три последовательно повышающихся по высоте тона:

```
низкий -> средний -> высокий
```

После короткой паузы последовательность повторяется.

Если используется осциллограф или логический/аналоговый измеритель, на аудиотракте должен наблюдаться периодический сигнал, частота которого меняется вместе с сообщениями Serial Monitor.

## Критерий PASS

После реального теста можно зафиксировать:

```
TEST_07_AUDIO_PASS
GPIO26_DAC_OUTPUT_CONFIRMED
AUDIO_440HZ_CONFIRMED
AUDIO_880HZ_CONFIRMED
AUDIO_1760HZ_CONFIRMED
AUDIO_PATH_CONFIRMED
```

`AUDIO_PATH_CONFIRMED` следует ставить только если подтверждён именно штатный аудиовыход/динамик платы, а не только электрический сигнал непосредственно на GPIO26.

## Важные ограничения

Это не тест качества звука. Он не измеряет:

- мощность усилителя;
- амплитудно-частотную характеристику;
- коэффициент гармоник;
- максимальную громкость;
- качество динамика.

Цель — только функционально подтвердить генерацию DAC-сигнала и прохождение через аудиотракт.

Не подключайте низкоомный динамик напрямую к GPIO26, если не подтверждена схема конкретной ревизии платы. Используйте штатный аудиовыход/усилитель платы.

## Техническая основа

Для оригинального ESP32 Arduino API предоставляет `dacWrite(pin, value)`, а GPIO26 соответствует DAC2. Официальная документация Espressif:

- <https://docs.espressif.com/projects/arduino-esp32/en/latest/api/dac.html>
