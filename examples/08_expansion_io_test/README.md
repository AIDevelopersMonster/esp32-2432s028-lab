# 08 — Expansion GPIO test

## Статус

**ГОТОВО К ПРОВЕРКЕ НА РЕАЛЬНОЙ ПЛАТЕ**

Пример пока не помечен как `VERIFIED`: на конкретной ревизии платы нужно физически идентифицировать контакты разъёмов и выполнить тест перемычкой.

Файл программы: [`08_expansion_io_test.ino`](08_expansion_io_test.ino)

## Что проверяет пример

Этот тест закрывает оставшиеся универсальные GPIO, выведенные на разъёмы расширения CYD:

- `GPIO22` — цифровой вход/выход;
- `GPIO27` — цифровой вход/выход;
- `GPIO35` — вход-only, также ADC1_CH7.

Главная автоматическая часть — двусторонний loopback между GPIO22 и GPIO27.

## Важное предупреждение по ревизиям CYD

Расположение контактов P3/CN1 может отличаться между ревизиями. В проектной документации типичные выводы зафиксированы в [`docs/pinout.md`](../../docs/pinout.md), но перед установкой перемычки обязательно сверяйте маркировку именно своей платы или прозванивайте дорожки.

Не используйте положение контакта на разъёме как единственное доказательство его GPIO.

## Требуется

- ESP32-2432S028R / CYD;
- одна перемычка Dupont для GPIO22 ↔ GPIO27;
- для ручной проверки GPIO35 — возможность временно подключить его к GND и 3V3;
- Arduino IDE и настройки из [`docs/arduino-ide.md`](../../docs/arduino-ide.md).

Дополнительные библиотеки не требуются.

## Безопасность

ESP32 использует логику 3,3 В.

**Не подавайте 5 В на GPIO22, GPIO27 или GPIO35.**

GPIO35 является только входом. Скетч не пытается переключать его в OUTPUT.

## Фаза A — GPIO22 ↔ GPIO27 loopback

До включения теста соедините одной перемычкой:

```
GPIO22 <-> GPIO27
```

Скетч сначала использует:

```
GPIO22 = OUTPUT
GPIO27 = INPUT
```

и 20 раз проверяет уровни LOW/HIGH.

Затем направление автоматически меняется:

```
GPIO27 = OUTPUT
GPIO22 = INPUT
```

и тест повторяется.

При успешном прохождении Serial Monitor должен показать:

```
EXPANSION_LOOPBACK_START
GPIO22_TO_GPIO27_PASS
GPIO27_TO_GPIO22_PASS
EXPANSION_DIGITAL_LOOPBACK_PASS
```

Это подтверждает как минимум цифровой вход и выход на обоих GPIO и электрическую доступность этих линий через выбранные контакты разъёма.

## Фаза B — GPIO35 input/ADC

После автоматического loopback скетч переходит к постоянному мониторингу GPIO35:

```
GPIO35 digital=0 adc=...
```

GPIO35 не имеет программного внутреннего pull-up/pull-down, поэтому в неподключённом состоянии показания могут плавать.

Для проверки:

1. подключите GPIO35 к GND;
2. убедитесь, что digital становится `0`, а ADC близок к нижней части диапазона;
3. отключите от GND;
4. подключите GPIO35 к `3V3`;
5. убедитесь, что digital становится `1`, а ADC заметно возрастает к верхней части диапазона;
6. снимите перемычку.

Не требуется считать точные значения ADC калибровкой. Здесь проверяется только реакция входа на два заведомо разных уровня.

## Критерий PASS

После полного реального теста можно зафиксировать:

```
TEST_08_EXPANSION_IO_PASS
GPIO22_OUTPUT_CONFIRMED
GPIO22_INPUT_CONFIRMED
GPIO27_OUTPUT_CONFIRMED
GPIO27_INPUT_CONFIRMED
GPIO35_DIGITAL_INPUT_CONFIRMED
GPIO35_ADC_INPUT_CONFIRMED
EXPANSION_CONNECTOR_ACCESS_CONFIRMED
```

Последний маркер следует ставить только после того, как подтверждено, что тест действительно выполнен через физические контакты разъёма конкретной платы.

## Что этот тест не проверяет

Он не проверяет автоматически:

- I2C-протокол;
- внешние датчики;
- допустимый ток GPIO;
- 5-вольтовую совместимость — её у GPIO нет;
- все возможные альтернативные функции GPIO22/27/35.

I2C имеет смысл проверять только с известным внешним устройством; это уже расширение лаборатории, а не встроенный узел CYD.

## Техническая основа

В ESP32 GPIO22 и GPIO27 могут использоваться как обычные цифровые GPIO, а GPIO35 относится к вход-only группе GPIO34–39. Официальная документация Espressif:

- <https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/peripherals/gpio.html>

После успешного прохождения этого теста базовое функциональное покрытие встроенных узлов и доступных разъёмов ESP32-2432S028R можно считать практически завершённым.
