# Примеры для ESP32-2432S028R

Этот каталог содержит последовательные учебные примеры для платы **ESP32-2432S028R (CYD)**. Каждый пример расположен в отдельной папке и снабжён собственным `README.md` с назначением, требованиями, порядком запуска, ожидаемым результатом и типичными неисправностями.

## Перед началом

Сначала выполните общую настройку Arduino IDE:

- [Установка и настройка Arduino IDE](../docs/arduino-ide.md)
- [Установка и первая проверка библиотеки CYD_Board](../libraries/CYD_Board/README.md)
- [Установка и настройка TFT_eSPI для ESP32-2432S028](../docs/tft-espi-installation.md)
- выберите плату **ESP32 Dev Module**;
- для примера тачскрина установите `XPT2046_Touchscreen`;
- откройте монитор порта на скорости **115200 бод**.

`BluetoothSerial` и BLE API для примеров 05–06 входят в пакет `esp32 by Espressif Systems`; отдельная установка Bluetooth-библиотеки не требуется. Примеры 07–08 также не требуют сторонних библиотек сверх `CYD_Board` для аудиотеста.

Примеры предназначены прежде всего для документированного профиля **ESP32-2432S028R с ILI9341 и XPT2046**. Близкие ревизии CYD могут иметь другой дисплей, другое направление цветов, иную калибровку тачскрина или отличающуюся разводку.

## Рекомендуемый порядок

| № | Пример | Что проверяет | Основной результат |
|---|---|---|---|
| 00 | [`00_board_test`](00_board_test/README.md) | Установку `CYD_Board`, RGB LED, LDR, кнопку BOOT | Библиотека компилируется, светодиод меняет цвета, в Serial выводятся LDR и BOOT |
| 01 | [`01_display_test`](01_display_test/README.md) | TFT ILI9341 и конфигурацию TFT_eSPI | На дисплее появляются текст, рамка и цветные поля |
| 02 | [`02_touch_test`](02_touch_test/README.md) | XPT2046 и отдельную SPI-группу тачскрина | На TFT и в Serial появляются сырые X/Y/Z |
| 03 | [`03_sd_test`](03_sd_test/README.md) | Безопасную read-only проверку microSD | В Serial выводятся размер карты и дерево уже существующих файлов |
| 03B | [`03_sd_rw_lab`](03_sd_rw_lab/README.md) | Создание каталогов, запись, повторное чтение и append | ESP32 создаёт `/cyd_lab`, записывает и проверяет файлы на нескольких уровнях |
| 04 | [`04_wifi_clock`](04_wifi_clock/README.md) | Wi-Fi, NTP и периодическое обновление TFT | На экране отображаются дата и время |
| 05 | [`05_bluetooth_classic_test`](05_bluetooth_classic_test/README.md) | Bluetooth Classic SPP и двусторонний обмен | Устройство `CYD-BT-CLASSIC` принимает и передаёт данные через SPP |
| 06 | [`06_ble_test`](06_ble_test/README.md) | BLE advertising, GATT READ/WRITE/NOTIFY | Устройство `CYD-BLE` обнаруживается, подключается и обменивается GATT-данными |
| 07 | [`07_audio_test`](07_audio_test/README.md) | GPIO26 / DAC2 и штатный аудиотракт | Последовательно формируются тоны 440, 880 и 1760 Гц |
| 08 | [`08_expansion_io_test`](08_expansion_io_test/README.md) | GPIO22, GPIO27 и input-only GPIO35 на разъёмах расширения | Двусторонний loopback 22↔27 и ручная проверка GPIO35/ADC |

Начинайте с `00_board_test`: это одновременно первая проверка локальной библиотеки `CYD_Board`. Перед `01_display_test` обязательно установите `TFT_eSPI` и примените наш `config/tft_espi/User_Setup.h`. Переходите дальше только после того, как предыдущий пример работает ожидаемо.

Для microSD лаборатория намеренно разделена на два этапа: сначала безопасный [`03_sd_test`](03_sd_test/README.md), который ничего не записывает, затем [`03_sd_rw_lab`](03_sd_rw_lab/README.md), который работает только внутри собственного каталога `/cyd_lab` и показывает практические операции с файловой системой.

Bluetooth также разделён на два этапа. [`05_bluetooth_classic_test`](05_bluetooth_classic_test/README.md) проверяет Classic SPP, а [`06_ble_test`](06_ble_test/README.md) — BLE advertising и GATT. Эти режимы используют встроенное радио ESP32 и не требуют внешнего Bluetooth-модуля.

Заключительная аппаратная пара — [`07_audio_test`](07_audio_test/README.md) и [`08_expansion_io_test`](08_expansion_io_test/README.md). Первый закрывает GPIO26/DAC и аудиотракт, второй — доступные универсальные линии расширения. Для `08_expansion_io_test` сначала физически идентифицируйте контакты конкретной ревизии платы: расположение P3/CN1 может отличаться.

## Как открыть пример

1. Откройте Arduino IDE.
2. Выберите **File → Open**.
3. Откройте `.ino` из нужной папки, например:

```
examples/00_board_test/00_board_test.ino
```

4. Выберите **ESP32 Dev Module** и COM-порт платы.
5. Нажмите **Upload**.
6. Для примеров с Serial откройте **Serial Monitor** на 115200 бод.

Имя `.ino` совпадает с именем папки, что соответствует требованиям Arduino IDE.

## Общая распиновка, используемая примерами

| Узел | Выводы |
|---|---|
| TFT | MISO 12, MOSI 13, SCLK 14, CS 15, DC 2, BL 21 |
| Touch | IRQ 36, MOSI 32, MISO 39, CLK 25, CS 33 |
| microSD | MISO 19, MOSI 23, SCLK 18, CS 5 |
| RGB LED | R 4, G 16, B 17, активный LOW |
| LDR | GPIO 34 |
| Audio | GPIO 26 / DAC2 |
| BOOT | GPIO 0 |
| Expansion lab | GPIO 22, GPIO 27, GPIO 35 input-only |

Bluetooth Classic и BLE используют внутренний радиотракт ESP32 и не занимают отдельные GPIO этой лаборатории.

Не переносите автоматически generic CYD pinout из других источников на эту ревизию. Для проекта используется профиль, зафиксированный в `CYD_Board` и документации репозитория.

## Что не делают эти примеры

Это отдельные минимальные проверки узлов. Они не являются полной интегрированной прошивкой и не доказывают одновременно:

- долговременную стабильность;
- совместную работу всех SPI-устройств;
- корректность конкретной калибровки тачскрина;
- одновременную работу Wi-Fi, Bluetooth Classic и BLE под нагрузкой;
- качество или мощность аудиотракта;
- все альтернативные функции GPIO расширения;
- пригодность любой другой ревизии CYD;
- производственную или полевую квалификацию.

Для каждого примера критерий успеха указан в его собственном `README.md`.
