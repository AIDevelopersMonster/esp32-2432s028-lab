# Примеры для ESP32-2432S028R

Этот каталог содержит последовательные учебные примеры для платы **ESP32-2432S028R (CYD)**. Каждый пример расположен в отдельной папке и снабжён собственным `README.md` с назначением, требованиями, порядком запуска, ожидаемым результатом и типичными неисправностями.

## Перед началом

Сначала выполните общую настройку Arduino IDE:

- [Установка и настройка Arduino IDE](../docs/arduino-ide.md)
- [Установка и первая проверка библиотеки CYD_Board](../libraries/CYD_Board/README.md)
- выберите плату **ESP32 Dev Module**;
- установите библиотеку `TFT_eSPI`;
- для примера тачскрина установите `XPT2046_Touchscreen`;
- скопируйте `libraries/CYD_Board` в каталог библиотек Arduino;
- примените конфигурацию `config/tft_espi/User_Setup.h`;
- откройте монитор порта на скорости **115200 бод**.

Примеры предназначены прежде всего для документированного профиля **ESP32-2432S028R с ILI9341 и XPT2046**. Близкие ревизии CYD могут иметь другой дисплей, другое направление цветов, иную калибровку тачскрина или отличающуюся разводку.

## Рекомендуемый порядок

| № | Пример | Что проверяет | Основной результат |
|---|---|---|---|
| 00 | [`00_board_test`](00_board_test/README.md) | Установку `CYD_Board`, RGB LED, LDR, кнопку BOOT | Библиотека компилируется, светодиод меняет цвета, в Serial выводятся LDR и BOOT |
| 01 | [`01_display_test`](01_display_test/README.md) | TFT ILI9341 и конфигурацию TFT_eSPI | На дисплее появляются текст, рамка и цветные поля |
| 02 | [`02_touch_test`](02_touch_test/README.md) | XPT2046 и отдельную SPI-группу тачскрина | На TFT и в Serial появляются сырые X/Y/Z |
| 03 | [`03_sd_test`](03_sd_test/README.md) | microSD и её отдельную SPI-группу | В Serial выводятся размер карты и дерево файлов |
| 04 | [`04_wifi_clock`](04_wifi_clock/README.md) | Wi-Fi, NTP и периодическое обновление TFT | На экране отображаются дата и время |

Начинайте с `00_board_test`: это одновременно первая проверка локальной библиотеки `CYD_Board`. Переходите дальше только после того, как предыдущий пример работает ожидаемо. Так проще отделить проблему общей настройки от проблемы конкретного узла.

## Как открыть пример

1. Откройте Arduino IDE.
2. Выберите **File → Open**.
3. Откройте `.ino` из нужной папки, например:

   ```text
   examples/00_board_test/00_board_test.ino
   ```

4. Выберите **ESP32 Dev Module** и COM-порт платы.
5. Нажмите **Upload**.
6. Для примеров с Serial откройте **Serial Monitor** на 115200 бод.

Имя `.ino` совпадает с именем папки, что соответствует требованиям Arduino IDE.

## Общая распиновка, используемая примерами

| Узел | Выводы |
|---|---|
| TFT | MISO 12, MOSI 13, SCLK 14, CS 15, DC 2, BL 21 |
| Touch | IRQ 36, MOSI 32, MISO 39, CLK 25, CS 33 |
| microSD | MISO 19, MOSI 23, SCLK 18, CS 5 |
| RGB LED | R 4, G 16, B 17, активный LOW |
| LDR | GPIO 34 |
| BOOT | GPIO 0 |

Не переносите автоматически generic CYD pinout из других источников на эту ревизию. Для проекта используется профиль, зафиксированный в `CYD_Board` и документации репозитория.

## Что не делают эти примеры

Это отдельные минимальные проверки узлов. Они не являются полной интегрированной прошивкой и не доказывают одновременно:

- долговременную стабильность;
- совместную работу всех SPI-устройств;
- корректность конкретной калибровки тачскрина;
- пригодность любой другой ревизии CYD;
- производственную или полевую квалификацию.

Для каждого примера критерий успеха указан в его собственном `README.md`.
