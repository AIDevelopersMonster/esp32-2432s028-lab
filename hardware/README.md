# Hardware

Каталог предназначен для собственных материалов по конкретному экземпляру платы:

- фотографии обеих сторон;
- измеренные размеры;
- распиновка разъёмов;
- схемы внешних подключений;
- файлы корпуса и креплений;
- замечания по ревизии.

Не размещайте чужие схемы или фотографии без проверки лицензии и источника.
