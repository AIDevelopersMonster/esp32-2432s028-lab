# B8 hardware acceptance campaigns

This directory contains board-specific working evidence for release candidate `v1.0.0-rc1`.

The immutable repository release matrix stays under `release/`. Each physical board receives a separate campaign directory under `qualification/boards/`. A campaign may be promoted only after every acceptance item is supported by retained evidence and the copied matrix passes the final all-PASS validator.
